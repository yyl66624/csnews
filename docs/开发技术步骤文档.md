# 一对一家教微信小程序 — 开发技术步骤文档

> 版本：v1.1 | 日期：2026-07-01 | 与 `下一阶段规划.md` 对齐

**产品范围说明：** 本平台为 **C2C 家教撮合平台**（预约、支付、线下/自行协商授课），**不包含在线音视频授课功能**。

---

## 项目定义

| 项目要素 | 说明 |
|----------|------|
| 产品形态 | 微信小程序（C2C 家教撮合平台） |
| 服务模式 | 平台提供一对一撮合，教师端入驻，学生/家长端发单 |
| 收费模型 | 向需求方（学生/家长）收取手续费，费率 **5%-9%** |
| 资金流 | 学生支付全额 → 微信分账：教师收款 + 平台手续费（自动拆分） |
| 教师端 | 免费入驻，不向教师抽佣，仅做资质审核 |

## 三、技术选型

| 层级 | 技术 | 选型理由 |
|------|------|----------|
| 小程序前端 | 微信原生框架 + TypeScript | 性能最优，与微信生态无缝适配 |
| 管理后台前端 | React + Ant Design | 生态成熟，组件丰富 |
| 后端服务 | Node.js + Nest.js | 轻量高效，适合快速迭代；与微信 SDK 生态兼容好 |
| 数据库 | MySQL 8.0 | 业务数据（用户、订单、教师、评价） |
| 缓存 | Redis 7 | 会话管理、热点数据（教师列表缓存） |
| 文件存储 | 腾讯云 COS | 教师资质证书、头像、教学资料 |
| 支付 | 微信支付 APIv3 + 分账 | 自动拆账：教师收款 + 平台手续费 |
| 短信/通知 | 腾讯云 SMS + 微信订阅消息 | 上课提醒、订单通知 |
| 部署 | 腾讯云轻量服务器 / CVM | 初期 2 核 4G 起步，后续弹性扩容 |
| CI/CD | GitHub Actions / 腾讯云 CODING | 自动化构建部署 |
